# Выбор места и маршрут 2ГИС

Цель: перенести выбор места с IMG-20261108-WA0007.jpg в действующий Flask-интерфейс и строить автомобильный маршрут внутри сайта. Существующий ключ проверен запросом к Routing API: HTTP 200, маршруты возвращаются.

Реализация в `templates/index.html`: отдельный адаптивный экран схемы, реальные места выбранной парковки; для 1–4 мест компактный ряд с проездом, для больших парковок — два ряда. Зелёные свободные, красные занятые с машинками, жёлтые забронированные с замком, синий выбор с подписью «Выбрано · свободно», карточка бронирования. Над схемой — общий счётчик свободных мест и отдельные количества занятых/забронированных. Количество и номера берутся из базы; демонстрационные места не добавляются. Форма и POST брони используют выбранный id. При изменении занятости выбор сбрасывается, другое место автоматически не подставляется. Старые ответы опроса не заменяют новые; после бронирования обновляется актуальный объект места.

Для маршрута используется существующая карта MapGL и официальный Directions plugin. Начало — геолокация по нажатию или клик по карте; конец — координаты парковки. Ошибки геолокации/сервиса отображаются с возможностью повторить; доступна ссылка на 2ГИС. Выход из маршрута возвращает на исходный экран. Существующие брони, RU/EN и мобильный интерфейс сохраняются.
