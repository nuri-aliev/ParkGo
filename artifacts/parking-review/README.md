# Проверка парковок — 9 ноября 2026

По запросу пользователя проведены независимая проверка интерфейса по спецификации и проверка координат по реальным парковкам.

## Занятость и дизайн

- Воспроизведено: запоздавший ответ `/api/spots` заменял более свежую занятость. Теперь ответы старых запросов отклоняются, в том числе после успешного бронирования/отмены.
- Счётчик и схема используют один снимок мест. Счётчик расположен над схемой, отдельно указаны занятые и забронированные места.
- Бронь обозначается замком и жёлтым цветом; машина изображается только на физически занятом месте. Синее место подписано «Выбрано · свободно»: выбор до подтверждения не уменьшает доступность.
- Для 1–4 мест используется компактный ряд, для больших парковок — два ряда с проездом. Исправлено выравнивание дороги и четырёх мест при горизонтальной прокрутке на телефоне.

## Проверки

`test_coordinates.py` проверяет попадание каждой из семи меток внутрь опубликованного полигона, включая исключение внутренних отверстий. `test_availability.cjs` воспроизводит ответы в обратном порядке, проверяет согласованность счётчика и схемы, а также различие выбора, брони и физической занятости. Остальные проверки покрывают бронирование, отмену, мобильный интерфейс и настоящий маршрут 2ГИС.
