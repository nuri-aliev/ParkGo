# ParkGo

Сайт парковок, бронирование, админ-панель и симулятор датчиков.
Нужен Python 3.10+ с pip и venv. Из папки проекта:

```bash
./start.sh
```

Скрипт создаст `.venv`, установит зависимости и запустит сайт:
**http://127.0.0.1:5050**. Остановка: Ctrl+C.
Порт 5000 на этом компьютере занят phpMyAdmin.
Для доступа из локальной сети: `PARKGO_HOST=0.0.0.0 ./start.sh`.
Другой порт: `PARKGO_PORT=5051 ./start.sh`; также измените `PARKGO_TARGET` в настройках бота.

Данные хранятся в `parking.db` рядом с `app.py`; для другой базы задайте `PARKGO_DB`.
Перед первым запуском после обновления сохраните копию базы.
Рабочий интерфейс находится в `templates/`, файлы backup и корневой `index.html` не используются.

Регистрация разрешена для почты `@astanait.edu.kz`.
Если администратора ещё нет, его пароль выводится при первом запуске.
Чтобы назначить свой пароль администратора, остановите сайт и выполните:

```bash
./start.sh make-admin admin@astanait.edu.kz 'ВАШ_НОВЫЙ_ПАРОЛЬ'
```

## QR-код, промокоды и зарядка

- Подтверждение и раздел «Мои брони» показывают QR-код активной брони. При сканировании читается текст вида `ParkGo booking #42`.
- В админке откройте **Promo codes**. Укажите срок в часах, общий лимит активаций и один эффект: скидка в процентах, скидка в тенге или дополнительные минуты. Пользователь добавляет код рядом с «Поддержкой» или при оформлении. Подтверждение брони расходует одну активацию, отмена её не возвращает. Скидка применяется к оценке стоимости выбранного времени. Дополнительные минуты увеличивают срок брони без увеличения этой оценки. В проекте нет платёжной интеграции.
- Значок вилки на карте показывает зарядку на парковке или рядом. Точный статус виден в карточке парковки. В админке **Parking → EV charging** можно отметить проверенную зарядку на территории парковки. Для восточной парковки EXPO рядом указана станция «Экспо-2» по [карте eDrive](https://edrive.kz/maps/?city=1&local=0).

Симулятор датчиков запускается дополнительно во втором терминале:

```bash
.venv/bin/python sensor_simulator.py
```

Он меняет занятость свободных мест; забронированные места пропускает.
На сайте и в симуляторе должен совпадать `PARKGO_SENSOR_TOKEN`.

## Telegram и Tailscale

Работающий бот: `/home/nuras/Documents/tgbot`.
Отправьте ему `/start` или `/status`: доступны **Управление компьютером**,
**ИКТ-проект** и **ParkGo**. ParkGo направляет на `http://127.0.0.1:5050`.
Выбор проекта сохраняет текущий режим доступа (Tailnet или Интернет).
Адрес выбранного сайта бот показывает в ответе. Сам бот сайт не запускает.

Для доступа без Tailscale выберите **ParkGo**, затем **Интернет** и откройте
**https://msi5050.tail6a914d.ts.net/** без `:5050`. Порт 5050 — локальный
адрес сервера, публичный HTTPS работает через Funnel на порту 443.
После включения Funnel обновление публичного DNS может занять до 10 минут.
Ошибка `DNS_PROBE_FINISHED_NXDOMAIN` в это время означает, что DNS ещё
хранит ответ «домен не найден». Подождите и перезапустите браузер.
Подробнее: [документация Tailscale](https://tailscale.com/docs/features/tailscale-funnel#dns-propagation).

## Автозапуск на этом компьютере

После первого успешного запуска установите пользовательскую службу:

```bash
mkdir -p ~/.config/systemd/user
cp deploy/parkgo.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now parkgo
```

Если сайт запущен в терминале, сначала остановите его.
Служба запускается с пользовательским сеансом. Управление:

```bash
systemctl --user status parkgo
systemctl --user restart parkgo
systemctl --user stop parkgo
journalctl --user -u parkgo -n 50
```

При переносе проекта исправьте абсолютные пути в `deploy/parkgo.service`.

## Подтверждение почты

Регистрация доступна после настройки SMTP с поддержкой STARTTLS. Укажите в окружении сайта `PARKGO_SMTP_HOST`, `PARKGO_SMTP_FROM`, при необходимости `PARKGO_SMTP_PORT` (по умолчанию 587), `PARKGO_SMTP_USER` и `PARKGO_SMTP_PASSWORD`. Пользователь получит ссылку, действующую один час; аккаунт создаётся после перехода по ней. Без настройки SMTP вход существующих пользователей работает, регистрация временно недоступна. Используйте адрес сайта, доступный получателю письма.
